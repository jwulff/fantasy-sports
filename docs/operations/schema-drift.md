# Schema-drift response SOP

Use this whenever a normalized command returns `SCHEMA_DRIFT`. An error is evidence that a source cannot be trusted for that read, not proof that its result is empty.

1. **Contain.** Record command, league/season, UTC `data_as_of`, error code/path, and affected decision. Do not advance that source's cursor or make a write that depends on it. Keep unaffected leagues and sources running. Report a material blocked action once.
2. **Inspect narrowly.** Reproduce once with `--fresh --output json --no-raw`. Use `raw --view <view> --fresh` only for a read-only shape comparison. Summarize keys, types, counts, and presence of fields; do not publish raw private payloads, credentials, or player/member identifiers in issues or fixtures. Confirm completeness and freshness before using raw data for a temporary read-only comparison. Never reinterpret a missing queue or truncated page as empty.
3. **Classify.** Separate a changed provider shape from auth, transport, stale cache, and a local parser bug. Identify the exact row variant and the consequence of excluding or normalizing it. Preserve an error for unknown or consequential malformed rows; only make a narrow exception when independent evidence proves it is metadata, not a move.
4. **Fix and prove.** Patch the adapter, add a sanitized regression for the observed variant and a negative test showing actual malformed moves still fail. Run relevant provider tests and lint. Verify the patched CLI against the live affected league, checking a fresh successful envelope, row count, and comparison with the raw view; do not claim a live fix from a fixture alone.
5. **Land and deploy.** Open a PR with the observed shape, limits of the exception, and test/live evidence. Resolve checks and review findings, merge, verify GitHub says `MERGED`, then update the installed CLI and repeat the fresh read with that installed binary. If installation or merge is blocked, say which and keep the source marked unverified.
6. **Resume safely.** Reconcile missed rows against the saved cursor and raw fallback window. Only advance state after a complete successful normalized read. Retain an interval-incomplete flag if the old cursor is outside the page; do not backfill by guesswork. Close with a concise report only if the repair or newly discovered activity materially changes John's decisions.

The 2026-11-06 Big Mac case was a `TRADE_ACCEPT` acknowledgement with no `status`, zero `items`, and a `relatedTransactionId`. It is not itself a player movement; the activity feed supplies trade movements. The adapter skips only this precise metadata shape. Missing `status` on a player-moving transaction remains `SCHEMA_DRIFT`.
