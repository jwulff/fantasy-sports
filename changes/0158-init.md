# `init`: one command from a fresh install to a first league read

## Why

Closes #158, part of #155. With the browser cookie import (#156) and league
discovery (#157) merged, a first run was still three commands plus a hand-edited
`config.toml`. `init` composes them so first run is `uv tool install` ->
`fantasy-sports init` -> `fantasy-sports league info`.

## How

- **Compose, don't reimplement.** The cookie import is `auth.login(from_browser=*)`
  itself, so `auth login` behaviour and its tests are untouched (and `auth.py`
  is not edited, which keeps this PR clear of the `--from-clipboard` work in
  #160). Discovery is `espn_fan.fetch_leagues`; slugs come from
  `leagues.slugs`; the write goes through `read_document` / `write_atomically`,
  so unknown top-level keys survive and the file mode is kept.
- **The SWID is resolved through the credential chain after storing**, exactly
  as `leagues discover` does, and passed to `fetch_leagues` and nowhere else.
  The envelope names a source and never a value. League *names* are left out of
  the rows: they are commissioner-set free text.
- **Current season = the latest season listed for a readable sport**, not a
  clock lookup, so the answer does not flip on a boundary date and hockey's
  `2027` cannot pull football's `2026` out of scope. Sports outside
  `READABLE_SPORTS` are reported `skipped` (`unsupported-sport`) and never
  written (#173).
- **`default`.** An explicit `default` is never changed. With none: one league
  written to an empty file becomes the default; a file with exactly one league
  gets that league's name written as `default` before a second arrives (it was
  the implied default, and two profiles without one make a bare `league info`
  fail, found by preflight); several leagues written to an empty file leave it
  unset and the envelope's `next_step` carries the one-line fix.
- **`--dry-run` writes nothing, `doctor` included** (its cache check creates the
  cache; `doctor` is `null` on a dry run). `config.toml` is parsed before the
  Keychain or ESPN is touched, so a broken file fails with nothing stored.
  A dry run reads the
  browser (or the stored cookies) so discovery can run, and never prompts, since
  a prompted answer would have to be stored to be used.
- **No browser, no terminal -> `AUTH_MISSING`** with a remediation that says why
  nothing was prompted. The TTY check is `init._stdin_is_tty`, a module function
  looked up at call time so tests inject it (not a default argument:
  `docs/memory/default-args-defeat-monkeypatch.md`).
- A slug already held by an unrelated league gets `-2`, `-3`, so a new season of
  a known league never replaces its older table.
- README "First run" collapses to the three commands; the five manual steps stay
  below as "Manual setup". The `init` sample embeds `doctor`, whose python and
  version lines belong to the machine, so it joins the samples exempt from
  offline regeneration (six became seven).

## Validation

- `tests/unit/test_init.py`: fakes for the browser search, `fetch_leagues`, the
  TTY check and the Keychain write; a `tmp_path` XDG config. Covers a fresh
  file, an overlapping league, unrelated keys, an existing default, a slug
  collision, a dry run, no browser on and off a terminal, an unparseable
  config, and the swid/cookie never appearing in the envelope.
- Run with `sys.platform` patched to `linux` as well as natively.
- Full suite (2799 passed, `init.py` at 100% coverage), ruff check and format,
  `check_budgets`, `check_startup` (18 ms cold `--help`), and
  `render_readme_samples.py --check`.
